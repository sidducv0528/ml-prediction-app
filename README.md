## 🎯 Models Inside

| Tab | Model | Algorithm | Accuracy |
|---|---|---|---|
| ☎️ Churn Predictor | Customer Churn | Random Forest | 80% |
| 🏥 Insurance | Premium Predictor | Linear Regression | R²=0.875 |
| 🏦 Bank Deposit | Subscription Predictor | Logistic Regression | AUC=0.992 |
| ❤️ Heart Disease | Risk Predictor | Decision Tree | 96.2% |

## ✨ Features
- Real-time predictions with interactive sliders
- Feature importance bar charts for every prediction
- Color-coded risk indicators (Green = Safe, Red = Risk)
- Fully responsive — works on mobile and desktop
- No backend or server required — runs in browser

## 🚀 How to Use
Just open `index.html` in any browser — or visit the live link above!
